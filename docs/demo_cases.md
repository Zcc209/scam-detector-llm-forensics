# 代表性案例

五個案例各展示系統的一個能力。以下都是實際在網站上執行的結果（2026-09-29，社群微調版 MacBERT＋融合模型 fusion-v1-social）。圖片放在 `data/demo/`，網址可直接貼進網站重跑；網頁內容會隨時間變動，結果可能略有不同。

| # | 案例 | 輸入 | 結論 | 展示的重點 |
|---|---|---|---|---|
| 1 | 真詐騙 | `data/demo/case1_invest_group.jpg` | 疑似詐騙 | 冒用名人的投資群組招攬：一句話也能抓出詐騙話術 |
| 2 | 正常帳號 | `https://www.threads.com/@dcard.tw` | 未發現明顯詐騙跡象 | 官方帳號的一般貼文不會被誤判 |
| 3 | 新聞討論 | `https://www.ptt.cc/bbs/DigiCurrency/M.1786064365.A.F39.html` | 未發現明顯詐騙跡象 | 「在討論詐騙」不等於「在詐騙」 |
| 4 | 仿冒網域 | `data/demo/case4_fake_myship_chat.jpg`、`instagram-login-verify.net` | 高度疑似詐騙 | 硬證據在模型之上做安全升級 |
| 5 | 需要人工查證 | `data/demo/case5_line_chat.jpg` | 需要人工查證 | 證據不足時不硬判 |

## 1. 真詐騙：冒用名人的投資群組招攬

**輸入**：`data/demo/case1_invest_group.jpg`，一則 Threads 貼文截圖：頭像是財經名人照片、帳號名稱是一串數字（`s178178`），內容只有一句：

> 進群組可加我賴ID：zy9784（不收費）

**結果**：疑似詐騙（融合分數 97.5%，只剩「詐騙」一種可能）

| 證據 | 內容 |
|---|---|
| MacBERT | 像詐騙文案的程度 93.1% |
| 帳號特徵 | 引導到站外聯絡：「加我賴」 |
| LLM | 判為「招攬讀者採取行動」 |

**展示重點**：文字只有一句，但「用名人頭像、邀請進群組、加 LINE、強調不收費」正是投資詐騙的開場話術，模型能抓到。這個案例沒有 165 名單、仿冒網域或已知詐騙圖這類硬證據，所以結論停在「疑似詐騙」；「高度疑似」保留給有硬證據的情況。

**小提醒**：OCR 把「賴ID：」讀成「賴|:」、把 zy9784 讀成 2y9784，截圖文字辨識難免有誤差，網頁上的「截圖上讀到的文字」會列出每一行讓人核對。

## 2. 正常帳號：Dcard 官方 Threads

**輸入**：`https://www.threads.com/@dcard.tw`

**結果**：未發現明顯詐騙跡象（融合分數 1.9%，只剩「正常」）

| 證據 | 內容 |
|---|---|
| MacBERT | 7.1%，偏向正常 |
| LLM | 判為「一般商品廣告」，沒有找到詐騙手法 |
| 帳號特徵 | 粉絲 69 萬（推向正常）；貼文中的「馬上」被標為催促用語，但影響很小 |

**展示重點**：即使貼文有行銷用語，只要沒有站外聯絡、保證獲利等手法，系統不會把正常品牌帳號當成詐騙。

## 3. 新聞討論：PTT 上討論詐騙新聞的文章

**輸入**：`https://www.ptt.cc/bbs/DigiCurrency/M.1786064365.A.F39.html`（〔閒聊〕慈濟採購疫苗遭遇詐騙、區塊鏈高峰會）

這篇文章來自**測試用的 PTT 看板**，訓練時沒看過。內容充滿「詐騙」「區塊鏈」「投資」等字眼。

**結果**：未發現明顯詐騙跡象（融合分數 0.14%）

| 證據 | 內容 |
|---|---|
| MacBERT | 0.7% |
| LLM | 判為「新聞／宣導」，沒有找到詐騙手法 |
| 連結追蹤 | 文章內的圖片連結都沒有異常 |

**展示重點**：關鍵字比對會把這類文章誤判成詐騙；本系統看的是「是否在招攬讀者行動」，所以能分辨「討論詐騙」與「進行詐騙」。

## 4. 仿冒網域：假 7-11 賣貨便

**輸入 A**：`data/demo/case4_fake_myship_chat.jpg`，一段 Messenger 對話截圖。對方說「我這邊傳您訂單填寫寄件資訊就好啦」「您確認收款後再到小七門市寄送」，並傳來連結 `myship7-11j.twi7j.sbs`，要求「在這裡填寫寄件資訊獲取單據收取款項」。

**結果**：高度疑似詐騙

| 證據 | 內容 |
|---|---|
| 模型的基礎結論 | 疑似詐騙（融合分數 97.4%；MacBERT 92.0%） |
| LLM | 判為「招攬讀者採取行動」，引用「您這裡填寫寄件資訊獲取單據收取款項喔」，歸類為要求登入或驗證帳號 |
| 連結追蹤 | 網址中出現「7-11賣貨便」字樣，但網域 `myship7-11j.twi7j.sbs` 不是官方網域 `7-11.com.tw`；使用 .sbs 高風險頂級域名；含隨機字串「twi7j」；目前無法連線 |
| 影像鑑識 | 畫面品牌（myship）與網址不符 |

結論卡會寫出：「模型的基礎結論是『疑似詐騙』；因為連結追蹤命中高風險規則，依安全優先原則提高為『高度疑似詐騙』」。

**輸入 B**：`instagram-login-verify.net` → 在第一層就被判定為仿冒 Instagram，**系統不開啟網頁**，直接回報高度疑似詐騙。

**展示重點**：模型先下基礎結論，硬證據再把風險往上調；硬證據只會提高風險，不會把結論改得更安全。

## 5. 需要人工查證：自我介紹前後矛盾的 LINE 聊天

**輸入**：`data/demo/case5_line_chat.jpg`，一段 LINE 對話截圖。對方自稱「我叫小婷 我20」「我住板橋區文化路一段這邊」，幾分鐘後又說「我住桃園市成功路一段這邊」，被使用者反問「妳剛不是說住板橋」。

**結果**：需要人工查證

| 證據 | 內容 |
|---|---|
| 融合分數 | 38.9%，落在 conformal 的兩條門檻之間，詐騙與正常都無法在 90% 信心水準下排除 |
| MacBERT | 49.5%，無法判斷 |
| LLM | 判為一般聊天，沒有找到詐騙手法 |
| 其他 | 沒有網址、帳號特徵或圖片證據 |

**展示重點**：這是交友詐騙常見的「罐頭開場白」（同一套自我介紹換地名重複發送），但對話還停在寒暄，沒有出現要錢、加群組、點連結等具體手法。系統**不下結論**，而是交給人工查證；人看得出「地址前後矛盾」這種情境線索，這正是拒答機制的用意。

**另一種人工查證**：`data/demo/benign_chat.png`（「今天天氣很好／我們下午去看電影吧／晚餐想吃拉麵」）MacBERT 給 78.8%，但只有 21 個字、沒有任何具體證據，系統同樣改為需要人工查證，避免冤枉一般使用者。
