# 代表性案例

五個案例各展示系統的一個能力。以下都是實際在網站上執行的結果（2026-09-28，社群微調版 MacBERT＋融合模型 fusion-v1-social）。圖片放在 `data/demo/`，網址可直接貼進網站重跑；網頁內容會隨時間變動，結果可能略有不同。

| # | 案例 | 輸入 | 結論 | 展示的重點 |
|---|---|---|---|---|
| 1 | 真詐騙 | `data/demo/official_fraud_invest.png` | 疑似詐騙 | 模型在沒看過的官方判定案例上抓出詐騙，LLM 提供可核對的引用 |
| 2 | 正常帳號 | `https://www.threads.com/@dcard.tw` | 未發現明顯詐騙跡象 | 官方帳號的一般貼文不會被誤判 |
| 3 | 新聞討論 | `https://www.ptt.cc/bbs/DigiCurrency/M.1786064365.A.F39.html` | 未發現明顯詐騙跡象 | 「在討論詐騙」不等於「在詐騙」 |
| 4 | 仿冒網域 | `data/demo/myship_fake.png`、`instagram-login-verify.net` | 高度疑似詐騙 | 硬證據在模型之上做安全升級 |
| 5 | 需要人工查證 | `data/demo/benign_chat.png` | 需要人工查證 | 證據不足時不硬判 |

---

## 1. 真詐騙：冒用名人的投資廣告

**輸入**：一則數發部「網路詐騙通報查詢網」上，主管機關判定為詐騙的一般網頁廣告（[原始案例](https://fraudbuster.digiat.org.tw/accessibility/detail?listType=N&id=f7189942e698f87007b5e8e4)），轉成截圖：

> 闕又上獨家台股觀察名單／精選20檔強弱勢股，附完整多空邏輯／不再被市場左右。／立即加LINE領取完整版！

這個案例屬於**測試集**，訓練時完全沒看過。

**結果**：疑似詐騙（融合分數 99.4%，只剩「詐騙」一種可能）

| 證據 | 內容 |
|---|---|
| MacBERT | 像詐騙文案的程度 95.4% |
| LLM | 判為「招攬讀者採取行動」，引用「精選20檔強弱勢股附完整多空邏輯」（保證獲利類話術） |
| 帳號特徵 | 催促用語「立即」 |

**為什麼不是「高度疑似」**：這個案例沒有 165 名單、仿冒網域、已知詐騙圖片這類硬證據，只有模型判斷，所以最高是「疑似詐騙」。「高度疑似」保留給有硬證據的情況。

## 2. 正常帳號：Dcard 官方 Threads

**輸入**：`https://www.threads.com/@dcard.tw`

**結果**：未發現明顯詐騙跡象（融合分數 1.9%，只剩「正常」）

| 證據 | 內容 |
|---|---|
| MacBERT | 7.1%，偏向正常 |
| LLM | 判為「一般商品廣告」，沒有找到詐騙手法 |
| 帳號特徵 | 粉絲 69 萬（推向正常）；貼文中的「馬上」被標為催促用語，但影響很小 |

**展示重點**：即使貼文有行銷用語，只要沒有站外聯絡、保證獲利等手法，系統不會把正常品牌帳號當成詐騙。

## 3. 新聞討論：PTT 上討論詐騙新聞的文章

**輸入**：`https://www.ptt.cc/bbs/DigiCurrency/M.1786064365.A.F39.html`（〔閒聊〕慈濟採購疫苗遭遇詐騙、區塊鏈高峰會）

這篇文章來自**測試用的 PTT 看板**，訓練時沒看過。內容充滿「詐騙」「區塊鏈」「投資」等字眼。

**結果**：未發現明顯詐騙跡象（融合分數 0.14%）

| 證據 | 內容 |
|---|---|
| MacBERT | 0.7% |
| LLM | 判為「新聞／宣導」，沒有找到詐騙手法 |
| 連結追蹤 | 文章內的圖片連結都沒有異常 |

**展示重點**：關鍵字比對會把這類文章誤判成詐騙；本系統看的是「是否在招攬讀者行動」，所以能分辨「討論詐騙」與「進行詐騙」。

## 4. 仿冒網域：假 7-11 賣貨便

**輸入 A**：`data/demo/myship_fake.png`（模擬假賣貨便話術：「填寫運費」「點擊獲取單據」，並附網址 `myship7 11j.twglo.sbs`）

**結果**：高度疑似詐騙

| 證據 | 內容 |
|---|---|
| 模型的基礎結論 | 疑似詐騙（融合分數 96.7%） |
| 連結追蹤 | 網址旁出現「7-11賣貨便」，但網域 `llj.twglo.sbs` 不是官方網域 `7-11.com.tw`；使用 .sbs 高風險頂級域名；目前無法連線 |
| 影像鑑識 | 畫面品牌（myship）與網址不符 |

結論卡會寫出：「模型的基礎結論是『疑似詐騙』；因為連結追蹤命中高風險規則，依安全優先原則提高為『高度疑似詐騙』」。

**輸入 B**：`instagram-login-verify.net` → 在第一層就被判定為仿冒 Instagram，**系統不開啟網頁**，直接回報高度疑似詐騙。

**展示重點**：模型先下基礎結論，硬證據再把風險往上調；硬證據只會提高風險，不會把結論改得更安全。

## 5. 需要人工查證：很短的聊天截圖

**輸入**：`data/demo/benign_chat.png`

> 今天天氣很好／我們下午去看電影吧／晚餐想吃拉麵

**結果**：需要人工查證

| 證據 | 內容 |
|---|---|
| 模型的基礎結論 | 疑似詐騙（MacBERT 78.8%） |
| LLM | 判為「個人生活分享」，沒有找到詐騙手法 |
| 其他 | 沒有網址、帳號特徵或圖片證據，截圖文字少於 30 字 |

**展示重點**：交友詐騙的「誘餌貼文」常常就是這種看似無害的閒聊，文字模型因此給出偏高的分數。但只有 21 個字、沒有任何具體證據時，系統**不下結論**，而是交給人工查證，避免冤枉一般使用者。

**另一種人工查證**：`https://www.instagram.com/104jobbank.official/` 的融合分數 15.6%，落在 conformal 的兩條門檻之間（5.1%～83%），詐騙與正常都無法在 90% 信心水準下排除，所以交給人工。這是統計門檻的結果，不是人為設定。
